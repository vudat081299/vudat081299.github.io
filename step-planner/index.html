      Data Science Step Planner

      Chia dự án thành bước và bước con

      Mỗi bước là một hàng, mỗi bước con là một thẻ. Theo dõi trạng thái, hạn; ghi quyết định; xuất Markdown.

      1. 1Chọn mẫu bên dưới, hoặc nhập file
      2. 2Bấm thẻ để sửa, bấm chip để đổi trạng thái
      3. 3Xuất Markdown để chia sẻ, sao lưu JSON để giữ

      Chọn mẫu

      Dữ liệu lưu trong trình duyệt này; sao lưu JSON để giữ hoặc chuyển máy.
